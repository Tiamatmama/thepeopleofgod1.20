# 点子发散

## 何时用
需要打开新解法空间、而非在既有方案里做取舍时：方案卡住、只有一种做法、要探索备选方向、要为验证阶段提供候选。**只负责造可能，不做可行性判断与排序。**

## 方法（按需挑，不必全用）
1. **SCAMPER 七问**：替代（Substitute）、组合（Combine）、借用（Adapt）、修改（Modify）、另作他用（Put to another use）、取消（Eliminate）、反转（Reverse）。对现状逐条套问，每条问「会变成什么」。
2. **类比迁移**：把别的领域已被验证的套路映射到当前问题——生物自愈、游戏机制（存档/关卡/成就）、仓储物流（排队/缓冲/批处理）、交通网络（路由/限流/重试/降级）、社会协作（评审/分工/留痕）。
3. **逆向假设**：先假设相反命题成立，看推出什么；或去掉一个当前「必须」的硬约束（必须实时/必须一致/必须有前端），看打开什么新空间。
4. **极端约束**：若成本必须为 0 / 若必须 1 秒内完成 / 若只能改一行 / 若规模放大 100 倍或缩到 1/100，方案会怎么变。
5. **组合创新**：把两个本来不相干的东西拼起来，看能否生出新解法。

## 输出格式
逐条列点子，每条只写：`一句话点子名` + `一句话说清它是什么` + `标签`。**不写理由、不评价、不排序**——那是收敛阶段的事。

## 铁律
- 只造可能，不判可行；越离谱越好，只怕没新意。
- 点子之间要彼此不同，禁止把一个点子换种说法凑数。
- 不重复已经提过的做法；已被淘汰的方向除非有新角度，否则不重提。
