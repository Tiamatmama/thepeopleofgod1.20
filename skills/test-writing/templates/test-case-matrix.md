# 测试用例矩阵模板

被测对象：`<函数/接口名>`
输入维度：`<如：name 长度、并发数、超时>`

| # | 类型 | 输入 | 期望结果 | 备注 |
|---|------|------|----------|------|
| 1 | 正常 | | | |
| 2 | 边界 | | | 刚好等于阈值 |
| 3 | 越界 | | | 刚好超阈值 |
| 4 | 空值 | null / '' | 期望明确失败或默认值 | |
| 5 | 异常 | 类型/格式错误 | 抛出可识别错误，不崩溃 | |
| 6 | 并发 | 同时 N 次 | 无竞态、状态一致 | |
| 7 | 回归 | 上一次出过的 bug 输入 | 不再复现 | |

使用说明：
- 每个维度至少覆盖「正常 / 边界 / 越界」三档。
- 每条都要有**可判定**的期望值，禁止写「应该正常」。
- 一个用例只验证一个点，失败时能定位到具体规则。
