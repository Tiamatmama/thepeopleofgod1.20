QQ 只读对接（OneBot v11）

            

                本系统通过 OneBot v11 协议对接 QQ 协议端，支持 NapCat 与 SnowLuma。
                先自行安装并登录其中一个，再把它的 HTTP 接口地址填到这里。
                
协议端需自备：NapCat / SnowLuma 是各自独立的软件，本系统 / 本包不含，需你自行安装、登录自己的账号并开启 HTTP 服务。
                只读：本系统不会以你的账号发出任何消息，仅能查看好友、群与历史消息。
